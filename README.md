# مشاور هوشمند زیبایی خانومی

مشتری نوع پوست، نیاز و بودجه را می‌گوید؛ برنامه از کاتالوگ زنده‌ی [خانومی](https://www.khanoumi.com/) محصولات **موجود** را پیدا می‌کند و با تصویر، قیمت، موجودی و لینک خرید پیشنهاد می‌دهد، روتین صبح و شب می‌سازد و چند محصول را مقایسه می‌کند.

## اجرا (ویندوز)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env      # بعد OPENROUTER_API_KEY را در .env بنویسید
python scripts\check_setup.py   # بررسی کلید، API خانومی و یک پاسخ کامل
uvicorn app.main:app --port 8000
```

مرورگر: `http://127.0.0.1:8000`

> اگر `check_setup.py` سبز نشد، نباید به بقیه مراحل رفت. خروجی‌اش دقیقاً می‌گوید کدام بخش مشکل دارد.

## چطور کار می‌کند

1. **برنامه‌ریز** (یک تماس سریع به مدل): پیام را می‌خواند و تصمیم می‌گیرد گپ ساده است یا نیاز به محصول دارد، ۱ تا ۴ عبارت جستجوی کوتاه می‌سازد و بودجه‌ی نوشته‌شده در متن را می‌فهمد.
2. **کاتالوگ**: عبارت‌ها موازی در API خانومی جستجو می‌شوند (فقط موجودها، با سقف بودجه). نتایج بین عبارت‌ها نوبتی ادغام می‌شوند و تا ۵۰ محصول می‌ماند.
3. **مشاور**: مدل فقط از همین فهرست انتخاب می‌کند. شناسه‌های ساختگی و محصول بالاتر از بودجه در سرور حذف می‌شوند.
4. **مقایسه**: قیمت و موجودی محصولات تیک‌خورده دوباره زنده خوانده می‌شود.

قیمت و موجودی همیشه از خانومی می‌آید و هرگز ساخته‌ی مدل نیست. نتایج جستجو ۳ دقیقه کش می‌شوند.

## تنظیمات `.env`

| متغیر | کاربرد |
|---|---|
| `OPENROUTER_API_KEY` | لازم |
| `OPENROUTER_MODEL` | پیش‌فرض `google/gemini-2.5-flash` |
| `OPENROUTER_FALLBACK_MODELS` | مدل‌های جایگزین، با ویرگول |
| `RATE_LIMIT_PER_MIN` | سقف پیام در دقیقه برای هر IP (پیش‌فرض ۱۲) |
| `TRUST_PROXY` | `1` پشت nginx/Cloudflare |
| `ALLOWED_ORIGINS` | برای جاسازی روی دامنه‌ی دیگر (CORS) |
| `KHANOUMI_PRICE_DIVISOR` | `10` اگر API قیمت را ریال بدهد |
| `USE_PLANNER` | `0` برای خاموش‌کردن مرحله‌ی برنامه‌ریز |

## مسیرها

- `POST /api/chat` گفتگو، پیشنهاد، روتین و مقایسه
- `GET /api/showcase` ویترین ۵۰ محصول
- `GET /api/health` وضعیت (مدل و وجود کلید)

## تست

```powershell
python -m unittest discover -s tests -t .
```

تست‌ها شبکه لازم ندارند (فروشگاه و مدل mock هستند).

## استقرار

```powershell
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

- نشست‌ها در حافظه‌اند؛ با چند worker یا ری‌استارت پاک می‌شوند. برای استفاده‌ی واقعی بعداً Redis بگذارید.
- حتماً پشت HTTPS و با `TRUST_PROXY=1` اجرا کنید تا محدودیت نرخ IP واقعی را ببیند.
- جستجو در `app/khanoumi.py` جداست؛ اگر خانومی API رسمی داد فقط همین فایل عوض می‌شود.

## محدودیت‌های شناخته‌شده

- API کاتالوگ خانومی رسمی/مستند نیست و ممکن است تغییر کند. `check_setup.py` آن را می‌سنجد.
- مدل فقط نام، برند و قیمت را می‌بیند، نه ترکیبات. بنابراین ادعای علمی درباره‌ی مواد مؤثر نمی‌کند. برای قدم بعد، توضیحات و ترکیبات صفحه‌ی محصول را به کاتالوگ اضافه کنید.
- این ابزار تشخیص پزشکی نمی‌دهد.
